## Why the name changed

The previous working name **Tenon** and the distribution **`tenonhq`** collided with the active
company at **tenonhq.com** (marketing automation on ServiceNow, with a $8M Series A). The old
surface was also crowded: PyPI `tenon` is a captcha package, npm `tenon` is the Tenon 2.x
accessibility package, `tenon.com` is Tenon Intersystems, and several GitHub projects use the name.
That blocker is **resolved** by the rename.

## Residual risk

- `sdkfit.com` is not owned; the launch uses `sdkfit.dev`. Acquire the `.com` later if it becomes
  available, and keep the `.dev` canonical.
- Do a trademark check in the launch jurisdictions before submitting; this record is not legal
  advice.
- Re-check the handles immediately before the launch in case a package or profile appears.
- The PyPI trusted-publisher setup in `docs/RELEASE.md` uses the `sdkfit` project and the
  `haqaliz/sdkfit` repository.
